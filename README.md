## ⚙️ Prosedur Sinkronisasi (_My Workflow_)

Sebagai _problem-solver_ di dalam tim, saya menerapkan standar rasional berikut sebelum menekan tombol _Pull Request_ (PR):

1. **Isolasi Bebas Konflik:** Saya melakukan `git pull origin main` secara berkala ke dalam _branch_ ini untuk memastikan eksperimen saya tidak bentrok dengan garis waktu utama.
2. **Self-Review (Skeptisisme Sehat):** Menguji argumen kode saya sendiri secara kritis. Apakah ini sudah solusi yang paling optimal?
3. **Commit Deskriptif:** Pesan _commit_ di _branch_ ini difokuskan untuk menjelaskan _mengapa_ logika tersebut diubah, bukan sekadar _apa_ yang diubah.
