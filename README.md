## 🛠️ Alur Kerja Kolaborasi (Workflow)

Untuk menjaga repositori tetap rapi, kami menyepakati alur kerja berikut:

1.  **Pendataan Tugas:** Melihat issue yang perlu dikerjakan.
2.  **Percabangan (Branching):** Anggota membuat *branch* baru dari `main` dengan format `feature/nama-fitur`.
3.  **Pengembangan:** Melakukan *coding* dan `commit` secara berkala di branch tersebut.
4.  **Sinkronisasi:** Melakukan `pull` dari `main` secara rutin untuk menghindari konflik besar.
5.  **Pull Request (PR):** Setelah selesai, anggota membuat PR ke `main`.
6.  **Review:** Atha (atau anggota lain) melakukan *review* kode.
7.  **Merge:** Jika disetujui, Atha akan melakukan *merge* ke `main`.
